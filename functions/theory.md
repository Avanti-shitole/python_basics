# Python Functions

A function is a reusable block of code used to perform a specific task.

## Why use functions?
- Avoid code repetition
- Make code easier to understand
- Make programs modular
- Easy to test and maintain

## Syntax

def function_name():
    # code

## Types of Functions

1. Built-in Functions
   Example: print(), len(), sum()

2. User-defined Functions
   Functions created using the def keyword.

## Function Parameters

Parameters are variables defined inside the function definition.

## Return Statement

The return statement sends a result back from the function.

## *args

Used to pass multiple positional arguments.

## **kwargs

Used to pass multiple keyword arguments.

## Recursion

A function calling itself is called recursion.

Example:
factorial(5) = 5 × 4 × 3 × 2 × 1 = 120
