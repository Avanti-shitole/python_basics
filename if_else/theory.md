# If / Else

If/Else is used to make decisions in a Python program.

### 1. if

Runs the code when the condition is `True`.

age = 20

if age >= 18:
    print("Adult")

2. if-else
Runs one block if the condition is true, otherwise another block.

age = 15

if age >= 18:
    print("Adult")
else:
    print("Minor")

3. if-elif-else
Used when there are multiple conditions.

marks = 75

if marks >= 90:
    print("A")
elif marks >= 60:
    print("B")
else:
    print("C")
Interview Questions

1. What is if/else?
It is used to make decisions based on conditions.

2. What is elif?
elif means "else if" and checks another condition.

3. Can we use multiple elif statements?
Yes, we can use multiple elif statements.

4. What is indentation in Python?
Indentation defines the block of code inside a condition.
