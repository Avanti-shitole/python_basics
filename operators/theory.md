# Operators

Operators are symbols used to perform operations on values.

### 1. Arithmetic Operators

Used for mathematical calculations.

| Operator | Meaning | Example |
|---|---|---|
| `+` | Addition | `10 + 5` |
| `-` | Subtraction | `10 - 5` |
| `*` | Multiplication | `10 * 5` |
| `/` | Division | `10 / 5` |
| `%` | Modulus | `10 % 3` |
| `//` | Floor Division | `10 // 3` |
| `**` | Power | `2 ** 3` |

### 2. Comparison Operators

Used to compare two values. They return `True` or `False`.

| Operator | Meaning |
|---|---|
| `==` | Equal |
| `!=` | Not Equal |
| `>` | Greater Than |
| `<` | Less Than |
| `>=` | Greater Than or Equal |
| `<=` | Less Than or Equal |

### Interview Questions

**1. What is an operator?**  
An operator is a symbol used to perform an operation on values.

**2. What is the difference between `/` and `//`?**  
`/` gives normal division, while `//` gives floor division.

**3. What does `%` do?**  
It returns the remainder of a division.

**4. What is the difference between `=` and `==`?**  
`=` is used for assignment, while `==` is used for comparison.
